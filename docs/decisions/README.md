# Decisiones de arquitectura (ADR)

Registrar las decisiones que afecten garantías, interfaces o evolución entre
fases. No hace falta crear un ADR para cada detalle.

## Plantilla

```text
# ADR-NNN: título
Estado: propuesta | aceptada | sustituida
Fecha:

## Contexto y requisito relacionado
## Decisión
## Alternativas consideradas
## Consecuencias y límites
## Cómo se verificará
## Referencias: Issues, contrato, pruebas y experimentos
```

Crear un ADR nuevo para una decisión relevante y enlazarlo desde los Issues y
los documentos afectados. No sobrescribir decisiones históricas: registrar su
estado y la decisión que las reemplaza.
