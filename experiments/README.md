# Registro de experimentos

Guardar una ficha por escenario/ejecución, basada en
`docs/experiments/TEMPLATE.md`. Mantener separados los resultados de cada fase:

- `phase-1-ray/`
- `phase-2-native/`
- `phase-3-comparison/`

No reemplazar registros anteriores al repetir un experimento. Identificar
configuración, commit, versión, workload, trigger, resultado e incertidumbre.
Los archivos voluminosos locales se mantienen fuera del control de versiones;
subir únicamente evidencia resumida y reproducible permitida por el curso.
