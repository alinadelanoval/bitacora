# Evidencia de experimentos

Guardar aquí evidencia reproducible y resumida, organizada por fase y por ID de
experimento. Incluir instrucciones/configuración y resultados legibles por
máquina cuando sea posible. No subir datos sensibles, volcados enormes ni
archivos temporales; mantenerlos fuera del repositorio o usar un almacenamiento
aprobado por el curso.
